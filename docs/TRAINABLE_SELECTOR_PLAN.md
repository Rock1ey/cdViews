# 下一阶段计划：训练问题引导的局部视觉选择器

状态：以下为阶段性设计记录。用户随后要求直接实现 R2，现已提供 R2 的代码与
[双卡训练/推理命令](R2_TRAINING.md)；R0/R1 的对照训练和 R3 集合模块尚未实施。

## 1. coverage 的处置

用户报告的相同配置结果（9 张、seed=42、temperature=0.2）：

| 方法 | EM@1 | BLEU-1 | ROUGE-L | CIDEr |
|---|---:|---:|---:|---:|
| cdViews 复现 | 29.1 | 44.7 | 47.4 | 96.5 |
| soft | 29.1 | 45.1 | 47.5 | 97.9 |
| coverage | 29.1 | 45.2 | 47.5 | 97.8 |

这是用户报告，未核查原始预测与 metrics 文件。coverage 相对 soft 的 BLEU-1 +0.1、
CIDEr -0.1，不足以支持它更优；单次结果也不足以证明该方向必然无效。

决定：实验主线退回 soft，停止继续调 coverage。保留 coverage 为独立消融选项和历史结果，
不执行 Git 历史回退、不删除预测。入口默认仍是 cdviews，原 soft 也是独立分支；没有必须撤销的默认行为变化。
后续结构实验先固定原 viewNMS，以避免把选择器变化和 soft 后处理混为同一个因素。

## 2. 已验证的实现问题：视觉 mask

`cdviews/ViewSelector.py` 第 53 行将所有视觉 token 的 mask 设为 True，
但 `MHAtt.att` 与 `AttFlat.forward` 都把 True 位置的打分填为 -1e9。
小型 CPU 检查直接调用当前模块（float32、关闭 dropout、随机输入），得到：

- 全 True 时 AttFlat 的输出与“先均值池化、再 linear_merge”完全相同；池化打分网络梯度为 0。
- 视觉自注意力的 Q/K 投影梯度为 0；V 投影梯度仍非零。
- 有效 token 设为 False 时，以上打分参数恢复非零梯度。

此结论只针对当前源码和模块行为，不证明作者 checkpoint 的实际训练代码与当前代码一致，
也不证明修正后 QA 一定提升。视觉残差、V 路径及视觉到文本交叉注意力仍存在，不能说模型看不到图像。

这是正确性修正，不能作为创新贡献。保留 legacy 实现与 checkpoint 对照；
新实验显式使用有效 token / padding mask，并重新训练，不直接给旧 checkpoint 换 mask 后冒充等价推理。

## 3. 推荐结构：问题引导的多查询视觉池化

优先改善单张图的细粒度表示，再考虑视图间交互。
当前代码在一张图内做 token 交互后，压成单个视觉向量；单图之间没有神经网络交互。
问题向量与视觉向量最终用余弦打分。当前全图 BLIP CLS 去重/覆盖没有改变这一表征瓶颈。

新结构第一版：

1. 保留冻结的 LLaVA-OV 视觉编码器与投影层，以及原问题 embedding 来源。
2. 保留选择器的 3584→256 投影、文本编码与现有图文融合骨干，正确处理 mask。
3. 替换单向量视觉池化：由问题表示和 4 个可学习查询产生查询向量，以视觉 token 为 K/V，
   用 cross-attention 提取 4 个局部摘要；拼接并投影回原来的 512 维视觉表示。
4. 保留 512 维问题表示、余弦评分及 `(cos+1)/2` BCE，先隔离结构变化，暂不更换损失。

4 个查询是可学习的潜在摘要，不预先宣称分别对应物体、属性、关系，也不保证天然不重复。
先做 1 查询与 4 查询的对照；不在同一版同时加入多种正则、损失、伪标签修正。

训练范围：选择器投影/融合/池化模块。冻结视觉编码器、投影特征提取器、LLaVA 语言模型；
不用 LoRA 微调整个 7B 问答模型。问题和视觉特征预计算后，训练阶段不需要常驻完整 7B。

## 4. 后续结构：视图集合上下文模块

只有局部结构通过对照后，再增加一个轻量视图级 Transformer（建议初值 1 层、256 维、4 头），
让同一问题的候选视图摘要彼此交互，再用残差方式修正各图表示。

- batch 保留 `[问题, 视图, token, 通道]` 及有效掩码；单图编码可暂时展平，
  在视图级 attention 前必须恢复问题分组，禁止不同问题/场景串在同一集合。
- 问题信息已通过局部查询进入视图摘要；第一版集合模块不再叠加位姿偏置和新损失。
- 为控制候选规模，可先研究固定的前 32 张重排序：使用冻结的第一阶段选择器生成候选，
  train/dev/val 按相同流程构造上下文，不用标签决定候选集合。其他帧保留第一阶段顺序。
  32 是待开发集验证的初值；必须统计候选正例召回，召回不足则扩大候选而非假定可恢复遗漏。
- 标签仅用于监督已标注视图；未标注和 Uncertain 视图可作为上下文，但不能自动当作负例。

这个模块是学习“候选集合上下文下的评分”。仅使用单图正负标签时，不能宣称学到了
“两张图组合后才能回答”的真实协同收益；若要直接优化该目标，需要训练集上的集合问答反馈。
这属于后续监督目标扩展，不与第一轮结构实验混做。

## 5. 训练数据、资源与协议

开始实现后的首个步骤是预检服务器资产，不能把已完成推理等同于已备齐训练数据：

- ScanQA train 标注和训练集 view_labeling（Positive/Negative/Uncertain）。
- 对应场景图像及 LLaVA 投影后的 patch-token 特征；BLIP 的 CLS 缓存不能替代这些特征。
- LLaVA checkpoint、作者 selector checkpoint（用于参考与可选初始化），磁盘和 GPU 可用量。
- 特征维度、帧名与问题 ID 覆盖。默认代码维度为 3584；实际 token 数要读取模型/样本确认。

默认 730×3584、fp16 的特征约 5 MiB/视图，完整缓存可能很大；先盘点已有特征和所需帧数。
预计算限定实际需要的 train/dev/val 场景/候选帧，batch size 可配置，不照搬原脚本一次 100 张。
所有资产/特征带模型配置与来源指纹；不同处理配置不共用无版本缓存。

仅从 ScanQA train 按场景固定划出约 10% 的内部开发集，seed=42，保存场景清单。
模型选择与早停使用内部开发集；官方 val 4,675 问用于固定版本的最终对照，不参与训练或选 checkpoint。
先保留原正负标签来源，不重新生成 caption，以免无法判断结构贡献。

首轮可沿用 Adam、lr=5e-5、最多 10 epoch、有效 batch=8 个问题的起点；
显存受限时减小实际 batch 并用梯度累积保持有效 batch。不同方法统一优化器、划分、采样、seed 和训练预算。
初始局部结构实验保留每问题至多 5 正/5 负的采样；加入集合模块时另做匹配部署上下文分布的采样对照。
训练记录 BCE、每问题 AP/正例 Recall@9、梯度和显存；这些是伪标签代理指标，不能代替最终 QA。
内部开发集的 checkpoint 选择规则预先固定（例如逐问题平均 AP），优胜结构再以多个训练 seed 验证。

## 6. 实验顺序与停止条件

| 阶段 | 变化 | 用途 |
|---|---|---|
| R0 | 原源码结构重训；保留原 mask | 与 R1 做同预算实现对照；历史发布 checkpoint 单独保留 |
| R1 | 仅修正视觉 mask 后重训 | 隔离实现修正，不能算创新 |
| R2 | R1 + 问题引导多查询池化 | 首轮主要结构假设；1 查询/4 查询可分步消融 |
| R3 | R2 + 视图集合上下文模块 | 后续实验，不与 R2 一次打包 |
| R4 | 最优结构 + 排序损失/其他监督 | 可选后续，结构效应明确后再做 |

R0/R1/R2 使用相同训练划分、预算、伪标签和原 viewNMS；QA 为 9 张、seed=42、temperature=0.2。
随后单独测试最优新选择器 + soft，保留现有 cdViews/soft 历史结果作端到端参考。
每次新 checkpoint 必须重新生成独立排序及原始分数；不读取作者旧排名伪装成新模型输出。

先验证小样本可过拟合、mask 梯度正确、padding 不影响有效输出、冻结骨干无梯度、分组无串扰，
再正式训练。结构若只改善伪标签指标而不改善开发集 QA，应分析被替换视图和错误类型，
暂停继续堆叠模块。只有在相同口径、完整 val 且跨 seed 更稳定时，才将新结构升级为主要结果。

## 7. 计划实现的工程范围

以下是计划文件/接口，不是已经可以执行的命令：

- 新的 selector 模型文件：保留 legacy、fixed-mask、query-pooling 三个明确变体。
- 特征预计算入口：冻结模型、可调 batch、清单和缓存指纹、已有特征完整性检查。
- 新训练入口：按场景 train/dev 划分、单卡、种子、恢复训练、最佳 checkpoint 和日志。
- 排序入口：由明确 checkpoint 生成新的排名和分数，记录 checkpoint/特征哈希。
- 扩展 `run_scanqa.py` 接受指定排序路径，验证相同候选池后复用原问答和评测流程。
- 后续集合版本再调整 Dataset/collate 的问题分组与候选上下文。

当前阶段不提供原 `cdviews/train.py` 的直接启动命令：它仍有旧路径、无内部开发选模，
且未显式阻断冻结 embedding 的梯度；直接启动不能实现上述受控对照。
